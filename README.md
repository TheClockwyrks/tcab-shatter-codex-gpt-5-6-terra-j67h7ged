# Shatter

Shatter is a browser space shooter set around a hungry gravity well. Turn, thrust, curve shots through the star's pull, and use a recharging guided torpedo to break armored asteroids.

Install dependencies with `npm ci`. Run a development server with `npm run dev`; create the static production site with `npm run build` (output is `dist/`).

Controls: Arrow keys or WASD steer/thrust, Space fires, F launches the torpedo, P or Escape pauses, M mutes, and Enter confirms menus.
